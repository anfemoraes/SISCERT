# SISCERT Frontend (React)

Dashboard inicial baseado na referência visual do Figma.

## Executar

```bash
npm install
npm run dev
```

## Observações
- Este é o protótipo de frontend: os números e registros exibidos são dados demonstrativos.
- Ainda não está conectado ao backend nem possui autenticação.
- Próxima etapa: configurar a URL da API e mapear os endpoints reais para certificações, agentes, cursos e relatórios.
